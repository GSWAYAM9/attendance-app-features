================================================================================
                       INSTALLATION SUMMARY
================================================================================

STEP 1: Database (2 minutes)
  1. Start MySQL
  2. Create database: CREATE DATABASE attendance_system;
  3. Import schema: SOURCE backend/db/schema.sql;
  4. Verify: SELECT * FROM employees;

STEP 2: Backend (1 minute)
  1. cd backend
  2. php -S localhost:8000
  3. Test: curl http://localhost:8000/api/employees/read

STEP 3: Frontend (1 minute)
  1. pnpm install
  2. Create .env.local
  3. pnpm dev
  4. Open http://localhost:3001

STEP 4: Test (1 minute)
  1. Navigate to Employees section
  2. Click "Add Employee"
  3. Fill form and submit
  4. Verify employee appears in list
  5. Test search and filter

================================================================================
                         API ENDPOINTS
================================================================================

EMPLOYEE ENDPOINTS:
  GET    /api/employees/read       - List all employees
  POST   /api/employees/create     - Add new employee
  PUT    /api/employees/update     - Update employee
  DELETE /api/employees/delete     - Delete employee
  GET    /api/employees/search     - Search employees

ATTENDANCE ENDPOINTS:
  POST   /api/attendance/checkin   - Employee check-in
  POST   /api/attendance/checkout  - Employee check-out
  GET    /api/attendance/get-history - Get attendance history
  GET    /api/attendance/stats     - Get statistics

For detailed API documentation, see: backend/README.md
